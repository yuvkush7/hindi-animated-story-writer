# संवाद-श्रेय: सही बनाम गलत

हर बोला गया वाक्य **मोटे अक्षरों में वक्ता का नाम** के साथ आना चाहिए: `**नाम:** "..."`।

## उदाहरण 1 — सामान्य संवाद

### ❌ गलत (कोई वक्ता नहीं)
```
"यह मीनार रात में क्यों चमकती है?"
"मुझे नहीं पता, पर मुझे डर लग रहा है!"
```

### ✅ सही
```
**तितली:** "यह मीनार रात में क्यों चमकती है?"
**गोलू:** "मुझे नहीं पता, पर मुझे डर लग रहा है!"
```

## उदाहरण 2 — कथन (narration)

### ❌ गलत (बिना श्रेय के वर्णन)
```
सूरज ढल चुका था और गाँव पर खामोशी छा गई थी।
```

### ✅ सही
```
**कथावाचक:** "सूरज ढल चुका था और गाँव पर एक अजीब सी खामोशी छा गई थी।"
```

## उदाहरण 3 — अनजान वक्ता

### ❌ गलत (रहस्यमयी वाक्य बिना श्रेय)
```
"जो मीनार में घुसेगा, वापस नहीं आएगा..."
```

### ✅ सही
```
**रहस्यमयी आवाज़:** "जो मीनार में घुसेगा, वापस नहीं आएगा..."
```

## उदाहरण 4 — वर्णनात्मक श्रेय के साथ भी टैग ज़रूरी

### ❌ गलत (श्रेय केवल गद्य में)
```
तितली ने पूछा — यह चाबी किसकी है?
```

### ✅ सही
```
**कथावाचक:** "तितली ने चाबी की ओर इशारा करते हुए पूछा।"
**तितली:** "यह चाबी किसकी है?"
```

> नियम: अंतिम आउटपुट से पहले हर संवाद और कथन का वक्ता-श्रेय जाँचना अनिवार्य है।
